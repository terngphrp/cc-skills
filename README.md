# cc-skills

Claude Code skills. Each skill lives in its own folder; copy or symlink a folder into `~/.claude/skills/` to install it.

| Skill | What it does |
|---|---|
| [create-mind-map](create-mind-map/) | Interactive learning mind map that starts from an overview and grows deeper on demand. Append-only nodes, per-node fact check, cross-links, highlights and notes, rendered as a single HTML page. |
